# Ícones de bandeiras de cartão

SVGs oficiais das bandeiras (Visa, Mastercard, Amex, Elo, Hipercard, Diners e um genérico), 780x500.

- Fonte: https://github.com/aaronfagan/svg-credit-card-payment-icons (pasta `flat/`)
- Licença: Apache-2.0 (ver `LICENSE-Apache-2.0.txt`). As marcas pertencem aos respectivos titulares.
- O app renderiza via `react-native-svg` (`SvgXml`) a partir de `src/components/payment/cardBrandSvgs.ts`,
  arquivo gerado a partir destes SVGs. Ao trocar um SVG aqui, regenere aquele módulo.
